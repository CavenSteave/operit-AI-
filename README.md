# operit-AI-

obsidian 和 operitAI 结合，可以把 Obsidian 当作知识库。

## 简介

本仓库演示如何将 Obsidian 笔记与 operitAI 集成，把 Obsidian 当作可搜索的知识库来使用，方便在本地或结合云端服务进行问答与知识管理。

## 功能亮点

- 将 Obsidian 笔记结构化为知识库
- 支持全文/关键词检索
- 与 operitAI 接口对接（示例/模板）

## 快速开始

1. 克隆仓库：

   git clone https://github.com/CavenSteave/operit-AI-.git

2. 按照仓库内的说明将 Obsidian 笔记导出或挂载到指定目录。

3. 配置 operitAI API Key（以环境变量或配置文件方式），并运行示例脚本。
